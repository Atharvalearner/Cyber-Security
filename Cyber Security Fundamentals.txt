1. Cybersecurity: Protecting systems, networks, and data from attacks or unauthorized access.
   Goal: Keep data safe, accurate, and accessible only to the right people.

2. CIA Triad (Confidentiality, Integrity, Availability) :
	1. Confidentiality: Only authorized users should access data.
		- Applies to content and existence.
		- supported by access control mechanism: cryptography & stenography, file permissions, white and black list
		- Enforcement relies on system services. eg. kernel
		Example: ATM PIN → only you should know it.
	2. Integrity: Data should remain accurate and unmodified.
		- Trustworthiness of data or resources.
		- Data and origin integrity
		- Prevention and Detection mechanism use for unauthorized access.
		- Correctness and trustworthiness verifies in Origin, transmission, storage
		Example: If you transfer ₹1000 via UPI, it must not become ₹10,000 or ₹100.
	3. Availability: Systems/data should be available when needed.
		Example: Banking app must be up 24/7 → no DDoS downtime.

3. Concepts :
	1. Threat: A potential danger that can exploit a vulnerability and cause harm to an organization’s assets (data, systems, networks).
		 : Potential danger (Hacker, Malware, Natural disaster).
	2. Vulnerability: A weakness or flaw in a system that can be exploited by a threat actor.
		 : Weakness (Unpatched software, weak password, Open Ports, unhandled Services).
	3. Exploit: The actual method or tool used by attackers to take advantage of a vulnerability.
	4. Risk: The potential impact (damage) if a threat exploits a vulnerability.
		 : Probability that a threat exploits a vulnerability → causes damage.
	5. Attack : Actions that cause violation of security.

4. Types of Hackers: 
	1. White Hat (Ethical) : Help organizations secure systems.
		Example: Bug bounty hunters finding flaws in Facebook.

	2. Black Hat (Criminal) : Steal, damage, or extort for money.
		Example: Ransomware gangs locking hospital systems.

	3. Grey Hat : Sit in between → break in without permission but not for evil (sometimes to show flaws).
		Example: A hacker who finds a bug and discloses it publicly without asking.

	4. Script Kiddies : Amateurs using pre-made hacking tools/scripts.
		Example: Teenager launching DDoS using free tools on school Wi-Fi.
