A brute-force attack is a password attack in which an attacker systematically tries every possible password combination until the correct one is found. The success of the attack depends on factors such as password length, complexity, and whether security controls like rate limiting or account lockout are in place. For example, guessing a 4-digit ATM PIN by trying all combinations from 0000 to 9999 is a brute-force attack. To prevent it, organizations use strong passwords, multi-factor authentication (MFA), account lockout, rate limiting, and secure password hashing.


Password Attacks : 
- Tools : John the Ripper, Hydra, Medusa, Hashcat
- Types :
	1. Dictionary Attack :
		Tries common wordspasswords from a list.
		Example Trying “password123” or “qwerty” before random guesses.

	2. Credential Stuffing :
		Uses previously stolen username and password combinations from one breach to attempt access to other services
		Example If your Netflix password leaks, hacker tries same password on Gmail.

	3. Password Spraying :
		Tries common passwords across many accounts (instead of one account).
		Example Testing “Welcome@123” on 1000 employee accounts.

	4. Keylogging :
		Malware records everything you type.
		Example Keylogger captures your Facebook password as you type.

	5. A rainbow table:
		a precomputed data structure used to speed up the recovery of passwords from certain unsalted password hashes.
		Instead of calculating everything from the beginning each time, precomputed information is used.
		

# Salting:
Salting is the process of adding a unique random value to a password before hashing it. It ensures that even if two users have the same password, their stored hashes are different, protecting against rainbow table attacks. It is implemented by generating a random salt during registration, combining it with the password, hashing the result using algorithms like Argon2 or bcrypt, and storing both the salt and the hash. During login, the same salt is used to verify the password.
