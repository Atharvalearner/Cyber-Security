Brute Force & Password Attacks : 
- Tools : John the Ripper, Hydra, Medusa, Hashcat
- Types 1. Brute Force Attack  Attacker tries all possible password combinations until correct.
		Example Guessing ATM PIN by trying all 0000–9999 combinations.

	2. Dictionary Attack  Tries common wordspasswords from a list.
		Example Trying “password123” or “qwerty” before random guesses.

	3. Credential Stuffing  Using leaked username-password combos from one site to log into another.
		Example If your Netflix password leaks, hacker tries same password on Gmail.

	4. Password Spraying  Tries common passwords across many accounts (instead of one account).
		Example Testing “Welcome@123” on 1000 employee accounts.

	5. Keylogging  Malware records everything you type.
		Example Keylogger captures your Facebook password as you type.
