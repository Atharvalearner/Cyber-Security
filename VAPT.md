**# Penetration Testing / Pentesting:**

an authorized and controlled security assessment in which security professionals simulate real-world attacks to identify and verify exploitable vulnerabilities in systems, networks, applications, or organizations.



**# Phases of Penetration Testing:**

1. Planning
2. Reconnaissance
3. Scanning \& Enumeration
4. Vulnerability Analysis
5. Exploitation
6. Post-Exploitation
7. Reporting



**# Simple Flow:**

*Company*

&#x20;   *↓*

*Permission Given*

&#x20;   *↓*

*Penetration Tester*

&#x20;   *↓*

*Simulates Attack*

&#x20;   *↓*

*Finds Weaknesses*

&#x20;   *↓*

*Provides Report*

&#x20;   *↓*

*Organization Fixes Issues*



**# Types of Penetration Testing:**

***1. Black Box / External Testing:*** The tester has external knowledge.

***2. White Box / Internal Testing:*** The tester has full Internal knowledge like Source code, Architecture, network diagram, etc.

***3. Grey Box Testing:*** The tester has partial knowledge of both internal and external.



**| ----------------------------- | ---------------------------------------------------------- |**

**| Vulnerability Assessment (VA) | Penetration Testing (PT)                                   |**

**| ----------------------------- | ---------------------------------------------------------- |**

| Identifies vulnerabilities    | Verifies whether vulnerabilities can actually be exploited |

| Broad scan                    | In-depth assessment                                        |

| Usually automated             | Combination of automated and manual testing                |

| Finds potential issues        | Demonstrates real impact                                   |

| Lower risk                    | Higher operational risk (performed carefully)              |

**| ----------------------------- | ---------------------------------------------------------- |**



**# Easy Memory Trick:**

**Vulnerability Assessment:** What vulnerabilities exist?
