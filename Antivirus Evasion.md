**# Antivirus evasion:**

It refers to techniques used by malware authors to avoid detection by security software.



**A. Obfuscation:** The malware changes its appearance.

**B. Packing:** Packing compresses or encrypts the malware.

**C. Encryption:** The malware encrypts parts of itself.

**D. Polymorphism:** Same Malware >> Changes Appearance >> Different Signature

**F. Delayed Execution**: Instead of running immediately, malware waits. eg. Wait 30 Minutes >> Execute

**G. Environment Checking:**

The malware checks:

Am I inside a VM?

Am I inside a Sandbox?

Am I inside a Debugger?



If: Yes >> Do Nothing
