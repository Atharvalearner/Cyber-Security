**# Trojan/Trojan horse:**

* a type of malware 
* that Disguises/Mask/Hide itself as legitimate or useful software to trick a user into installing or executing it.
* A Trojan generally does not self-replicate. It typically relies on social engineering to trick a user into installing or executing it.



**# Trojan wrapping:** 

concept of combining or disguising malicious code with a legitimate-looking application so the user executes the malicious component while believing they are running normal software.



*Looks Legitimate*

&#x20;     *↓*

*User Trusts It*

&#x20;     *↓*

*User Executes It*

&#x20;     *↓*

*Hidden Malicious Activity Starts*



**# Example, a file may appear to be:**

Game, Software Update, PDF Tool, Cracked Software, Email Attachment, Mobile Application

but after execution it performs hidden malicious activity.



**# Depending on the Trojan, it may:**

* steal information
* create a backdoor
* download additional malware
* log keystrokes
* modify files
* communicate with attacker infrastructure
