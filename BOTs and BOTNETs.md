**# BOT:**

* a compromised computer, server, mobile device, or IoT device that is remotely controlled by an attacker without the owner's knowledge.
* Normal Computer >> Malware Infection >> Attacker Gains Control >> BOT (Zombie)



**# BOTNET:**

* a network of multiple compromised devices (Bots) that are remotely controlled by an attacker through Command and Control (C2) infrastructure.
